# Founder Repo OS Community

Founder Repo OS is a governed repository operating foundation for founders and teams building with AI-assisted development. It helps turn project context into reviewable repository changes while keeping the repository owner in control of the final decision.

## What it does

- Connects an authorized customer workflow to GitHub.
- Prepares repository-specific operating rules and setup changes.
- Shows the complete proposed diff before review.
- Uses a review-first Draft Pull Request workflow.
- Keeps repository governance boundaries visible.
- Includes relevant product maintenance updates during an active subscription.

## The review-first workflow

```text
Customer Account
      |
      v
    GitHub
      |
      v
   Full Diff
      |
      v
   Draft PR
      |
      v
Human Review
      |
      v
Explicit Merge
```

Founder Repo OS is designed to prepare a dedicated branch and Draft Pull Request. The repository owner reviews the proposed changes and decides whether to merge them. It does not present an automatic merge as part of the workflow.
